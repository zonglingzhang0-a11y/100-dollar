# 100-dollar · 百元漂流记

一个外乡人路过小镇，在客栈住了一晚，付了一张百元钞。之后这张钞票就在镇上漂流：
谁拿到它，就用它还账、买东西；收钱的人找不开零钱时，要么让对方再挑点东西凑数，要么打一张欠条。

这个页面跟着这张钞票走，把每一次转手写进流水账，并算一笔账：**一张 100 块的钞票，到底替全镇还掉了多少旧账？**
（跑上一个月，通常是它面值的十几到二十几倍。）

再往后看，故事就变了：照原来的规矩，全镇欠账头两个星期往下掉，之后一路往上涨，一年后通常比开局还多。
页面下半部分的 **镇上的规矩** 可以给小镇加规矩，同时模拟 40 座小镇各一年，看哪条规矩能让欠账稳住。

## 怎么打开

不需要安装任何东西：

- 直接双击 `index.html` 用浏览器打开；
- 或者在仓库目录里起一个本地服务器：`npm start`（等同 `python3 -m http.server 8000`），再打开 <http://localhost:8000>。

页面上可以：

- **播放 / 暂停**，或者点 **下一次转手** 直接跳到钞票下一次换手；
- 调 **慢 / 中 / 快** 三档速度；
- 点地图上任何一户人家，看这户人家欠谁、谁欠这户人家、零钱有多少；
- 在 **种子** 里输入任意文字生成另一座小镇。同一个种子永远是同一段故事；
  只含字母、数字的种子会写进网址（例如 `index.html#k3x9qa`），可以分享给别人；
- 在 **镇上的规矩** 里勾选规矩：上面的小镇会用同一个种子从头再来，下面的图会对比原来的规矩和勾选的规矩，一年里欠账怎么走。

## 原来的规矩

- 每个种子生成约 20 户人家：客栈、饼铺、肉铺、裁缝铺、私塾……每户有名字、零钱、脾气（大手大脚到一分钱掰两半花）和常去的几家铺子。
- 开局时大家互相欠着账，其中有一条从客栈出发、绕一圈又回到客栈的债务环，跟那个流传很广的寓言一样。
- 钞票只在白天（7:00–21:00）转手。持有人先还 **欠得最多、又找得开零钱** 的那笔账；没账可还时，看脾气决定要不要去买东西。
- 找零的顺序：先拿零钱找 → 零钱不够就再挑几样东西凑数 → 剩下 10 块以内的零头算了 → 再多就打欠条。
- 舍不得破开整钞的人会用零钱还小账，所以钞票有时会在某个人的饼干盒里躺好几天。
- 镇上其他人也在过日子：有人赊账，有人拿零钱还账（流水账里灰色的那些行）。
- 钞票每过一次手都会磨损一点，偶尔还会沾上铺子里的东西：面粉、鱼腥味、一根红线……

## 可以加的五条规矩

| 规矩 | 怎么回事 | 一年后的欠账（相对开局，60 座小镇的中位数） |
| --- | --- | --- |
| 不加规矩 | 原来的样子 | 1.43 倍，第二年还在每天涨 5 块左右 |
| 赊账有度 | 一个人欠全镇的账加起来过了 200 块，谁家都不再赊；零钱够的可以当场现买 | 0.51 倍，基本走平 |
| 以工抵债 | 欠了 200 块以上、手头没钱、一个礼拜没摸到钞票的人，去最大的债主那里帮一天工，30 块工钱抵账 | 0.62 倍，基本走平 |
| 照顾生意 | 手头宽裕的人拿闲钱出门买东西，一半时候特意去欠债人家；收了现钱的人转手先还账 | 0.33 倍，基本走平 |
| 三角债清理 | 逢七赶集，把绕成圈的欠账按圈上最小的一笔对冲掉 | 1.46 倍，照样往上涨 |
| 第二位外乡人 | 第 2 天又来一张百元钞，镇上的整钞多了一倍 | 1.07 倍，照样往上涨 |

（数字来自 60 个种子各模拟两年；页面上的实验用当前种子派生的 40 座小镇，数字会略有不同。）

### 为什么有的管用，有的不管用

还账不会让谁变穷或变富：拿钞票还也好，拿零钱还也好，只是把欠条换成现钱，各家的身家不变。真正让身家变化的只有买卖。

镇上总有几户人家，别人很少去他们铺子里买东西，他们自己却天天要吃饭穿衣。这几户买得多、卖得少，身家一天天往下掉，窟窿只能用欠账填。照原来的规矩，一年后全镇大部分欠账都压在三四户人家身上。

所以只改“怎么付钱”的规矩帮不上忙：多一张钞票，转手多了一倍，可钞票照样在不缺钱的人之间打转（试过一次放 16 张，欠账还是在涨）；欠账很少绕成圈，三角债清理一回只能抵掉几块。改了“谁挣、谁花”的规矩才管用：赊账有度让欠得多的人少花，以工抵债和照顾生意让他们多挣。
